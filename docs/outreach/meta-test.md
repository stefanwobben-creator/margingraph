# Meta-copytest — €50, vier dagen, één vraag: welke belofte klikt?

Dit is een meting, geen omzetkanaal. We kopen geen klanten, we kopen kennis:
welke van drie beloftes laat een eigenaar van een handelsbedrijf stoppen met
scrollen. De winnaar wordt de kop van álles daarna (site, mails, volgende
campagne).

## Instellingen (één campagne, drie advertenties)

| Instelling | Waarde |
|---|---|
| Doel | Verkeer (landingspagina-weergaven) |
| Budget | €50 totaal, 4 dagen, campagnebudget (Advantage uit) |
| Landen | Nederland + België |
| Leeftijd | 30–60 |
| Interesses | E-commerce, ondernemerschap, Shopify, bol.com verkopen |
| Plaatsingen | Alleen Facebook-feed + Instagram-feed (handmatig, geen Advantage+) |
| Beeld | Alle drie hetzelfde: screenshot van de cascade-tabel van /idea (donker, cijfers zichtbaar). Zelfde beeld, want we testen de kop, niets anders. |

Bestemmings-URL per advertentie (kopieer exact):

```
https://margingraph.com/for/ecommerce?utm_source=meta&utm_campaign=copytest&utm_content=vracht
https://margingraph.com/for/ecommerce?utm_source=meta&utm_campaign=copytest&utm_content=37cent
https://margingraph.com/for/ecommerce?utm_source=meta&utm_campaign=copytest&utm_content=boekhouder
```

## Advertentie 1 — "vracht"

**Primaire tekst:**
Webshop met uitbesteed fulfilment? Dan zit er in je winst-en-verliesrekening
één regel die bijna altijd lekt: het verschil tussen wat verzenden je kost en
wat je klanten ervan terugbetalen. Wij zetten die twee regels onder elkaar.
Eén bestand, gratis zie je wat erin zit, het volledige rapport kost €9. Geen
€90 aan actie gevonden = niets betalen.

**Kop:** Je verzendkosten-regel verstopt vaak duizenden euro's

**Beschrijving:** Eén bestand. €9. Niets gevonden = gratis.

**CTA-knop:** Meer informatie

## Beslisregel (vooraf vastgelegd, zodat we achteraf niet gaan praten)

- Na 4 dagen: hoogste CTR (link clicks / impressies) wint. Die kop wordt de
  werkkop voor alles daarna.
- CTR onder 0,8% bij alle drie: de boodschap is fout, niet het kanaal. Geen
  euro extra tot de tekst herschreven is.
- Kliks maar geen enkele upload: de landingspagina is het probleem, niet de
  advertentie. Dan ga ik /for/ecommerce herbouwen.
- We kijken níét naar likes, bereik of "engagement". Alleen CTR en uploads.

## Jouw handelingen

1. Ads Manager → nieuwe campagne "MG copytest juli" met de instellingen
   hierboven.
2. Drie advertenties, teksten hierboven exact plakken, per advertentie de
   juiste utm-URL.
3. Screenshot van de cascade op margingraph.com/idea als beeld (1080×1080
   bijsnijden werkt prima).
4. Start. Vier dagen niet aanraken, ook niet als dag één tegenvalt.
