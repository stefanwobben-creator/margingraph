# Glossary

> fields and UI copy. A knowledge graph company that is sloppy about its own vocabulary will
> build a sloppy graph.
>
> **Rule.** If a term appears in the [Ontology](../02-graph/ontology.md), the ontology is
> authoritative and this file links to it rather than redefining it.
